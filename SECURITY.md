# Security

Please do not include credentials, private keys, access tokens, production payloads, or other secrets in public issues.

For a security issue in this repository or the related InterAI Risk Oracle service, contact `interailabs@gmail.com` with enough detail to reproduce the problem safely.

This repository contains open-source host-side enforcement logic only. It does not contain the hosted Risk Oracle decision engine, production stores, signing keys, billing systems, private policy implementation, or operational secrets.
